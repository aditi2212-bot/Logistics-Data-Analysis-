# Dataset

This project uses the Brazilian E-Commerce Public Dataset by Olist.

The following datasets are used:

- olist_customers_dataset.csv
- olist_geolocation_dataset.csv

The customer dataset contains customer identifiers and geographic information such as ZIP-code prefixes, cities, and states.

The geolocation dataset provides latitude and longitude information associated with ZIP-code prefixes.

These datasets are combined to create interactive geographic visualizations of customer distribution.

## Dataset Source

Kaggle:

https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

The raw CSV files are not included in this GitHub repository.

Download the dataset from Kaggle and upload the required CSV files to Google Colab before running the analysis.
